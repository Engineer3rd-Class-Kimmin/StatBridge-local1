# 요약 지표명·표시기간·필수 계산 입력 보완

ai-assisted · 공개 개발 자료에서 발견한 현상을 일반 규칙과 합성 회귀 테스트로 재현했다.

요약용 이름을 무조건 가운데점 앞에서 자르면 구성 항목, 두 지역의 합계, 금리차의 평균이 다른 계열처럼 서술됐다. 코드·각주와 중복된 일반 항목만 정리하고, 공백 없는 가운데점은 지표명의 일부로 유지한다. 축약 후 다른 원래 이름이 같아지는 경우 양쪽 모두 원래 이름을 사용한다. 원자료·계산 식별자와 수치는 변경하지 않는다.

관측 요약은 기존 표시 서식으로 부동소수점 표시 잡음을 정리하며, 기간 비교를 ‘표시 시작 시점’으로 명명한다. 변화폭 설명에는 전월·전분기·전년 대비라는 인접 관측 비교 기준을 넣는다. 설명 선택 모델은 서버가 만든 사실 ID만 고르는 구조를 유지한다.

0으로 표시될 작은 관측값은 유지하되 이 작은 값의 표시 경로에서만 부동소수점 잡음을 정리한다. 큰 금액의 정수부와 소수 둘째 자리 정밀도는 유효 숫자 제한으로 줄이지 않는다. 원자료·계산 기록은 표시 서식의 영향을 받지 않는다.

연도를 생략한 뒤쪽 월·분기와 연속 월 입력을 해석한다. 한 숫자로 요청한 산술 결과의 표시기간은 원자료 기간과 구분해 종료 시점 한 점으로 계획하며, 명시적 표시기간은 우선한다. 입력 기간을 정답이나 관측값으로 바꾸거나 달력의 빈 시점을 채우지 않는다. 실제 계산식과 선행 이력은 기존 DAG 검증을 거친다.

비교문 뒤에서 분모의 기준 월·분기를 다시 설명해도 처음 지정한 비교 대상 시점을 유지한다. 사전 확인의 기간 코드는 주기와 함께 검증하며, 분기의 `YYYY01..04`를 달력 월과 혼용한 응답은 실제 관측 조회 전에 한 번만 형식 수정을 요청한다. `YYYY06`을 분기 코드로 임의 해석하지 않는다. 단일 결과를 표 전용으로 잘못 계획한 경우에도 한 번의 출력 형식 피드백만 제공하고 원래 수식·출력 수·기간과 의미 검토는 유지한다. 명시적 표 전용 지시는 그래프 출력으로 덮어쓰지 않는다.

원자료 사전 확인의 `role`은 `calculation`, `display`, `definition_only`다. 기본값은 `calculation`이며, 실제 계산이나 별도 원자료 출력에 필요한 계열은 계속 검증한다. 정의만 된 미사용 계열은 계산·보완 파일의 필수 입력에서 제외한다. 최종 계산의 승인 API 의존성 검사와 의미 검토는 유지한다. 띄어쓰기 없는 복합 검색어도 실제 메타데이터 어휘로 모두 분해될 때만 후보를 확장하며, 정확한 ID·항목·분류 선택 검증은 그대로 수행한다.

`rolling_sum`은 창의 전체 합계이며 표시 시작점부터 누적하는 `cumulative_sum`과 구분한다. `rolling_median`은 홀수 창의 중앙값, 짝수 창의 가운데 두 값 평균이다. `rolling_range`는 창의 최댓값−최솟값이며 차이 단위를 사용한다. 세 연산은 2~120개 시점과 기존 계산량 한도를 따르고 모든 달력 시점이 있어야 한다. 중앙값 정렬의 작업량도 검증·실행 한도에 반영한다. 스키마 밖 코드 실행은 허용하지 않는다.

경제심리지수 원계열은 한국은행의 [공식 공표](https://www.bok.or.kr/portal/bbs/B0000501/view.do?nttId=11062198&menuNo=201264)에 근거해 계산용 단위를 `지수`로 분류한다. 이는 KOSIS가 `UNIT_NM`을 반환했다는 뜻이 아니다. API 단위가 비어 있고 기관 301, 표·항목·월 주기·원계열 분류가 모두 일치하는 원응답에만 적용한다. 실제 API 단위가 있거나 다른 계열이면 이 규칙을 사용하지 않는다. 원응답과 공식 정의의 출처를 별도 기록한다.

검증:

```powershell
$env:PYTHONPATH='src/backend;src/agent'
python -m pytest -q tests/test_report_semantics_regressions.py tests/test_period_statistics.py tests/test_derived_availability.py tests/test_verified_source_units.py
python -m pytest -q tests eval/table-discovery/v4.1/tests
python eval/table-discovery/v4.1/scripts/validate_v41.py
```

합성 테스트는 실제 모델/API 실행으로 표시하지 않는다. 기존 RAGAS 점수와 원응답을 보존하고, 실제 재실행과 새 Judge 점수는 별도 실행 ID로 기록한다. 표 정의의 사실 근거 부족은 제품 수치 오류나 요약 지표명 손실과 구분한다.

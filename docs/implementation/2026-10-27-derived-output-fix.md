# 원자료와 계산 결과 출력 보완

ai-assisted. 기능 브랜치 `fix/report-raw-and-calculated-output`에서 작업하며 사람의 검토 후 반영한다.

## 문제와 동작

원자료와 증가율을 함께 표에 요청한 계산 계획에서, 원자료 alias를 출력으로 참조하면 계산 노드만 허용하던 검증기가 실행을 중단했다. 검증된 source alias도 출력 참조로 허용한다. 알려지지 않은 참조, 중복 이름, 원자료 출처·단위·주기·수치 변조는 계속 거부한다. 원자료를 복사하기 위한 가짜 계산을 추가하지 않는다.

`ExpressionOutput.display`는 `both`(기본), `table`, `chart`를 지원한다. 기존 계획은 양쪽 출력으로 유지한다. 표 문서와 표 내보내기는 표 계열을 사용하고, 그래프와 보고서 JSON/SVG/PDF는 그래프 계열을 사용한다. API의 `tableSeries`와 `visualization.series`를 각각 사용해 표 편집 항목도 올바르게 표시한다.

KOSIS의 `YYYYQ1..4`, `YYYYH1..2` 관측 코드는 계산 입력 검증 시 해당 주기에 한해 내부 기간 코드로 바꾼다. 잘못된 분기·반기나 정규화 후 중복 시점은 거부한다. 원본 응답과 계산 근거의 실제 응답은 보존한다.

기준시점 대비 상대 변화율은 `base_change` 연산으로 `(당기/기준시점-1)×100`을 계산하고 `%`를 유지한다. `base_period`는 필수이며 기준값의 누락·0, 비율 원자료의 상대변화에 관한 기존 검증은 유지한다. 지수끼리 뺀 포인트를 퍼센트로 오표기하거나 임시 상수 계열을 만들지 않는다. 계산 근거 화면에도 이 산식을 표시한다.

복수 지표의 기준과 지역은 각각의 독립된 요청 절에 묶는다. 일부 계열만 선택했거나 분류가 미확정이면 성공으로 처리하지 않는다. 연간 조회는 승인 메타데이터가 제공하는 주기로 선택하며 월별 관측값을 임의 합산하지 않는다. 계정 이름과 금리가 결합된 표현, 차입금리 동의어, 통계 분류에 붙은 합계도 구분한다. 국내 한국은행 GDP의 국가·통화를 불필요하게 되묻지 않되, 외국·외화 요청과 계산 정의의 실제 모호함은 보존한다.

SNA의 기준연도는 조회 연도로 해석하지 않는다. 잔액표와 거래표를 함께 요청하면 기본 화면은 패널을 나눈다. 자료 확인 단계는 원문에 명시된 통계표의 실제 항목·분류·주기를 먼저 제공하고, 메타데이터로 해결되는 질문을 줄인다. 이미 서버가 검증해 모델에 제공한 표는 검색 히트가 없더라도 메타데이터를 다시 확인할 수 있으며, 제공되지 않은 ID는 계속 거부한다.

실제 관측 응답에서 확인한 단위는 정확한 표·항목·분류·주기와 함께 계획자 및 의미 검토에 전달한다. 이력 간 단위가 다르거나 확인되지 않으면 확정 단위를 만들지 않는다. 의미 검토의 선택 설명에는 서버가 검증한 ID와 명칭의 연결을 보존한다. 파생 출력의 빠른 렌더링에서도 자연어 그래프 종류 요청을 유지한다.

## 검증과 경계

합성 관측 회귀 테스트로 원자료/계산값의 표·그래프 분리, 기존 계획 호환성, 원자료 변조 거부, 분기·반기 코드 및 중복 시점을 확인한다. 공개 메타데이터 테스트는 서로 다른 통화량 기준, 전체·지역별 경상수지, 연간 주기 및 미지원 계열의 누락 방지를 확인한다.

실제 제품 검증은 별도 로컬 서버와 브라우저에서 원래 질의만 입력한다. 응답·화면을 먼저 저장하고 해시로 고정한 뒤 별도 채점한다. 첨부된 정답·참조 HTML·관측 스냅샷·스크립트를 제품 입력, 계획 프롬프트, 원자료 대체로 사용하지 않는다. 결과·인증 DB·계산 근거는 무시된 `evaluation_runs/`에 보관하고 커밋하지 않는다.

중간 실행은 50문항 중 표·그래프 출력 46개, 별도 정량 채점 통과 44개·실패 5개·대기 1개였다. 미출력 3개 외에 기준시점 변화율 단위 오류 2개가 확인되어 추가 수정했다.

추가 수정 후 전체 50문항 실행은 46개 통과·3개 실패·1개 대기였다. 실패는 의미 검토의 통계표명 오판(35), 선그래프 요청 소실(38), 이미 확인한 단위의 계획 단계 전달 누락(40)이었다. 세 원인을 보완하고 사전 지정한 7문항(실패 3개 및 대조 21·41·49·50)을 한 차례씩 실행해 6개 통과·1개 대기를 확인했다. 두 실행을 반영한 문항별 최신 상태는 **49개 통과·0개 실패·1개 대기**다. 41번의 비율 배율·전월 변화 정의는 전달 README도 검토 대상으로 명시했으므로 확인 질문을 오답으로 확정하지 않는다. 전체 실행과 재검증을 각각 보존하며, 단일 실행 성능과 합성한 최신 상태를 구분한다.

실행·입력 격리·문항별 점수는 무시된 `evaluation_runs/v14-patch-results-20261027/`에 있다. 원자료와 선행 이력 1,438개 관측값을 문항별 최신 근거에서 첨부 스냅샷과 대조했다. 화면 가독성은 표본을 확인했으며 사람의 최종 승인과 별개인 개발 평가 결과다.

검증 결과:

- 전체 `tests` 및 `eval/table-discovery/v4.1/tests`를 128개 파일에 걸쳐 4개의 독립 pytest 프로세스로 실행했다. 2,392개 통과·1개 실패, 355개 subtest 통과였다. 실패한 ‘기준금리’ 미지원 판정은 금리 계정명 합성 규칙을 좁혀 수정했다.
- 마지막 수정 후 파생지표 관련 475개가 통과했다. 별도 관련 79개 검사에는 위 카탈로그 회귀와 신규 단위 전달 테스트가 포함되며 모두 통과했다. 마지막 수정 후 재실행 범위는 이 두 검사로 기록한다.
- `validate_v41.py`: `VALIDATION OK`.

## 2026-10-28 ME14-41 정의 확정과 단독 재검증

ai-assisted. 사용자가 전월 변화를 **전월 비율과의 차이**로 확정했다. [보완 질의](../../eval/end-to-end/v1.4/clarifications/ME14-41.jsonl)에는 `(부산 잔액 / 서울 잔액) × 100(%)`와 `당월 비율 − 전월 비율(%p)`를 명시하고 첫 달 계산을 위한 2020년 12월 조회를 요청한다. 기존 전달본과 보류 결과는 보존한다.

동일하고 확인된 단위의 두 입력을 백분율로 나누는 `percent_ratio` 연산을 추가하고, 그 결과에 기존 `difference(lag=1)`를 연결한다. 원래 `divide`는 배 단위를 유지한다. 분모 0·결측, 서로 다른 단위 배율, 비율의 상대 증감률에 관한 기존 검증은 유지한다. 정의가 미확정인 다른 질문의 해석을 일괄 변경하지 않는다. 제품 변경은 스키마·단위 검증·계산 엔진·계획자·산식 표시의 다섯 파일이다.

해당 보완 질의 하나만 실제 화면에 입력했다. 추가 질문 없이 표와 선그래프를 생성했고, 48개월의 원자료·계산값 192개 및 계산에 쓰인 원자료·선행 관측값 98개를 출력 고정 후 별도로 대조해 통과했다. 표에는 두 지역 잔액·비율·전월 차이, 그래프에는 비율만 표시했다. 실행·화면·점수는 무시된 `evaluation_runs/v14-me14-41-clarified-20261028/`에 기록한다. 다른 49문항은 기존 실행 결과를 유지한다.

관련 회귀 테스트 77개, 전체 회귀 테스트 2,402개 및 355개 subtest, v4.1 데이터 검증, TypeScript·Vite 빌드가 모두 통과했다. 전체 129개 테스트 파일의 실행 범위를 확인했다. 중간 대화 중단으로 수집기가 종료되어 완료된 네 pytest 로그에서 결과를 복구했으며, 관측하지 못한 프로세스 종료 코드는 생성하지 않았다. 별도 패치는 현재 작업 트리에 대한 역방향 적용 검사로 검증했다.

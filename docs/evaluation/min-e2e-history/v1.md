# v1: 편집·파일·파생 60문항의 UI 평가

평가일 2026-10-23 · ai-assisted · 사람의 골드 라벨 공식 승인 대기

## 목적과 첫 평가

편집 요구 정합성, 화면/파일 정합성, 파생지표 계산을 각각 20문항으로 구성했다. 실제 Chrome UI에서 새 컨텍스트 로그인, 자연어 질의, 대상/시점 선택, 편집, 되돌리기, 저장/재열기, 다운로드를 실행했다. 실제 모델을 사용했으며 원자료는 공개 KOSIS 응답을 공급 경계에서 고정 재생했다. 전체 60건의 실시간 KOSIS 성능으로 해석하지 않는다.

원보고서 첫 줄에는 과거 표기인 `min-e2e/1.1`이 남아 있다. 이 정리에서는 저장 경로 `eval/min-e2e/v1/`와 편집·파일·파생 60문항 구성을 기준으로 v1이라고 부르며, 조회·역질문 40문항의 v1.1과 섞지 않는다. 원보고서는 소급 수정하지 않았다.

| 단계 | 보고서의 관측 | 해석 |
|---|---:|---|
| 최초 제품 baseline | 54/60 | 실행기 수정과 복구 시도를 포함한 baseline map. 단일 무중단 최초 실행 아님 |
| 편집 패치 후 전수 | 58/60 | PDF/SVG 축 제목 누락 2건 잔존 |
| 내보내기 패치 후 전수 | 59/60 | D18 UI 대기 분류 실패 잔존 |
| 모든 패치 후 `release-final` | 60/60 | 동일 빌드에서 편집·파일·파생을 새로 전수 실행한 기록 |

## 부족했던 점과 개선

| 문항·증상 | 부족했던 처리 | 수정과 확인 |
|---|---|---|
| E04·E07·E19: 계열/표시별로 요청한 색이 같아짐 | 가상 `차트` 색 선택이 원래의 개별 색 지시보다 우선 | 실제 색상표를 쓴 경우에만 최종 덮어쓰기 안내를 전송하고 원문별 대상을 보존 |
| E14: 범례 재표시 요청에 위치만 변경 | 표시 여부와 위치 명령이 분리되어 재표시가 빠짐 | 명시한 표시와 위치를 함께 반영. 위치만 바꾸는 경우 임의 재표시하지 않음 |
| F13·F14: PDF/SVG X축 제목 누락 | 화면의 기본 `시점`을 인쇄 렌더러가 적용하지 않음 | 시계열 기본 제목을 인쇄에도 적용하고 명시 제목을 보존 |
| D18: 서버 계산은 끝났지만 UI 대기 종료 | 기호 뺄셈이 일반 질의 20초 예산에 남음 | 명시 산식·산술평균을 파생 120초 예산에 연결하고 유사 표현 6문항도 점검 |
| 전체 회귀 종료 정체 | 종료된 Langfuse 클라이언트 큐를 다시 flush | 클라이언트 분리와 중복 종료 처리 보완 |

UI 대상 선택·복수 그림 표시와 평가 실행기의 접근성 이름, 속성 패널 열기, 서버 준비 대기도 보완했다. 실행기 문제를 제품 실패에 섞지 않았다. 핵심 수정 영역은 `Sujeongi.tsx`, `ChartSketchEditor.tsx`, `derivedDeadline.ts`, `chart_edit_agent.py`, `chart_edit_intents.py`, `report_export.py`, observability였다.

## 최종 기록과 한계

최종 보고서는 편집 20/20, 화면/파일 20/20, 파생 20/20을 기록한다. PNG 14·PDF 1·SVG 1·CSV 3·XLSX 1개를 확인했고, 표 수치·숫자 셀과 이미지/문서 의미 일치를 검수했다고 서술한다. E12/E13은 필요한 확인 질문이 통과 조건이며, D20은 일부 월이 빠진 상태에서 계산을 중단하고 부족 월을 안내해야 통과한다. 모든 문항에 결과물을 생성해야 성공인 평가가 아니다.

당시 보고서의 회귀 결과는 기본 2,327개와 subtest 355개 통과, 실패/오류/건너뜀 0, 프런트엔드 빌드·v4.1 검증 통과다. 이는 이번 PR에서 새로 실행한 검사와 구분한다.

원시 `baseline-summary.json`, 최종 `scores.json`, `run-manifest.json`, `assistant-review.json`, UI/파일 및 JUnit·로그가 놓였던 `evaluation_runs/min-e2e-v1/`은 현재 로컬에서 찾지 못했다. 따라서 첫/최종 수치를 원시 파일로 다시 계산하거나 화면 검수를 재수행하지 못했다. 두 금리 중심의 공개 개발 회귀이며 전체 통계표 일반화나 사람 승인 성능으로 주장하지 않는다.

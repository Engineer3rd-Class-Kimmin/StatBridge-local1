# 고난도 v2.1: 문맥·간접 계산·조건 해석 개선

2026-10-27 · ai-assisted · 공개 개발 평가 · 사람 의미 판정 승인 대기

## 평가 목적과 최초 실행

v1.1의 조회·역질문·유형 분류 각 20문항을 각각 1:1 대응하도록 다시 작성한 고난도 60문항이다. 우회 표현, 흩어진 조건, 부정/정정, 인용된 제목과 후보, 간접 연산, 메타데이터 판단을 조합했다. 각 문항은 이전 상태 없는 질문 하나로 실행한다.

실행용 `questions.jsonl`의 질문만 제품에 전달하고, 원응답을 저장·동결한 뒤 채점자가 공개 정답을 읽었다. 조회/역질문은 FastAPI TestClient의 실제 `/api/query`와 실제 KOSIS를 사용했고 분류 20개는 `is_derived_request()`의 로컬 함수 평가다. 브라우저 UI·그래프·클릭이나 단일 모델의 성능을 뜻하지 않는다.

| 항목 | 최초 보고값 | 제품 패치 후 새 코호트 |
|---|---:|---:|
| 조회 | 5/20 | 20/20 |
| 역질문 | 6/20 | 20/20 |
| 유형 분류 | 5/20 | 20/20 |

최초 보고값은 문자 그대로 모든 요청의 최초 시도만을 모은 점수가 아니다. 초기 메타데이터 준비 대기 12건을 미리 고정한 정책에 따라 같은 질문·빈 상태로 재실행해 `final-predictions/`를 채점했다. 의미 오류였던 다른 문항은 재시도하거나 수정하지 않았다. 중단된 API 수집기의 349개 실제 응답으로 목록을 완성한 경위도 별도 기록했다.

## 부족했던 점과 제품 개선

| 실패 유형 | 첫 평가에서 관측한 예 | 개선 |
|---|---|---|
| 제목·인용·미래 작업을 계산으로 오인 | 제목의 증가율, ‘전월 대비 변화는 다음 작업’, 이동평균 제외 | 현재 요청의 유효 문맥을 추출해 조회와 계산 분기에 공통 적용 |
| 간접 계산을 일반 조회로 분류 | 1/6씩 반영한 한 숫자, 두 금리의 간격, 최대/최소 거리 | 동일 가중 평균·차이·범위·중앙 위치·배율/재지수화의 의도 인식 |
| 확정된 계열·분류를 확대/변경 | 잔액만 요청했는데 신규 포함, 중소기업만인데 대기업 포함 | 조건·제외·정정의 적용 범위 보존과 일상어 기준 정규화 |
| 표시 기간 오해 | 첫 석 달·첫 분기를 월별 1~12월로 확대 | 1~3월 해석, 기준연도와 관측기간 분리 |
| 실제 최신월·조정 기준 소실 | CQ21-16 종료 202608, 공식 원계열 마지막 관측 202609, 순환변동치 중복 | 요청한 계열의 실제 관측월까지 조회하고 이미 정한 조건 유지 |
| 미확정 기준 질문과 계산 보류 경계 | 기준 누락을 놓치거나 특정 연산 금지를 전체 중단으로 해석 | 필요한 기준만 질문하고 전체 보류와 특정 잘못된 순서 금지를 분리 |

표·분류에 흩어진 검색 근거와 후보 제한도 보완했고, 검색이 잘렸다는 이유로 자료 부재를 단정하지 않도록 했다. 생산 코드에 문항 ID·정답·문항별 계산 계획을 넣지 않았다고 당시 구현 기록이 명시한다.

## 재평가 해석

최종 별도 60문항 코호트는 세 항목 각각 20/20이다. 원계열의 최신월은 독립 API 조회와 같은 202609까지 확인했다. 현재 최초/최종 점수 파일의 영역별 집계와 보고서를 대조했다. 질문과 라벨을 유지한 공개 개발 회귀이며, 같은 실행 조건으로 v1.1을 다시 측정하지 않았으므로 난이도 상승 효과를 점수 차로 단정하지 않는다.

조회는 기관·표·항목·분류·주기·기간·단위·수치, 역질문은 필요한 미확정 조건을 정확히 물었는지로 판단했다. CQ21-15 기간 오류는 별도 기록했고 CQ21-17/20 계산값은 역질문 점수에 사용하지 않았다. 의미 판정은 ai-assisted이며 사람 검토가 남아 있다.

데이터셋 README/manifest의 `미실행`·`not_run`은 작성 시점 상태이고 뒤의 실제 평가 기록과 시점이 다르다. 이번 PR에서 원본 manifest를 소급 수정하거나 새로운 공식 점수로 갱신하지 않는다.

## 재현 명령

동일한 입력과 코드 해시는 manifest.json에, 원예측 해시는 output/predictions-frozen.json에 기록했다. run.py를 새 실행 디렉터리에 복사한 다음 저장소 루트에서 아래 단계를 순서대로 실행한다. 기존 실행 파일은 덮어쓰지 않는다.

```powershell
.\.venv\Scripts\python.exe -X utf8 evaluation_runs/<새 실행 디렉터리>/run.py prepare
.\.venv\Scripts\python.exe -X utf8 evaluation_runs/<새 실행 디렉터리>/run.py predict
.\.venv\Scripts\python.exe -X utf8 evaluation_runs/<새 실행 디렉터리>/run.py score
```

실행 생성물은 Git 제외 경로 evaluation_runs/에만 보관한다.

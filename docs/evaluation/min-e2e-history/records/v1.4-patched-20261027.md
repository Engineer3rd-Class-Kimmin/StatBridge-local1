## 변경

- 검증된 원자료와 계산 결과를 함께 출력하고, 표 계열과 그래프 계열을 구분한다. 원자료 변조·미확인 참조 검증은 유지한다.

- 기준시점 대비 변화율을 올바른 산식과 % 단위로 계산한다.
- 의미 검토에 서버가 실제 조회한 ID·명칭을 함께 전달하고, 확인한 원자료 단위를 계획 단계에 연결한다.
- 파생지표의 선그래프 요청이 출력 단계까지 유지되도록 한다.

## 실행과 채점 분리

실제 브라우저에서 원문 질의와 execute=true만 /api/query에 보냈다. 정답·참조 HTML·오라클 관측값·이전 상태·확정 선택을 모델 또는 제품 실행 입력에 넣지 않았다. 자동 출력 요청의 자연어도 원문이다. 응답·DOM 표·Plotly 계열·화면을 먼저 저장해 해시로 고정한 다음, 별도 채점 프로세스에서 첨부 참조값과 비교했다. 첨부 실행 스크립트는 실행하지 않았다.

A는 기관·표·항목·분류·주기, B는 전체 표시기간과 선행 이력, C는 원자료·계산값·단위, D는 실제 DOM 표, E는 실제 Plotly 시점·계열·값·단위 구분·출처를 확인했다. 수치 허용오차는 원수치 1e-6, 화면 소수 6자리 반올림을 고려한다. 비교시점 값은 전달 rubric이 허용한 대로 계산 근거에서 확인할 수 있다. 표와 그래프의 필수 계열은 각각의 질의와 전달 기준을 따른다. 화면 가독성은 표본을 직접 확인했으며 사람의 최종 검토·승인은 대기다.

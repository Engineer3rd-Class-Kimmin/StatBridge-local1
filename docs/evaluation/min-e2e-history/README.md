# 최소 E2E 평가 이력: 첫 관측에서 개선·재검증까지

2026-10-29 정리 · ai-assisted · 공개 개발 평가 · 사람의 최종 결과·정성 승인 대기

2026-10-23~28에 기록된 v1, v1.1, 팀원 v2, 고난도 v2.1, 전달본 v1.4의 첫 평가와 개선 과정을 정리한다. 이번 PR은 과거 문서와 현재 남아 있는 점수 파일을 대조한 **문서화 작업**이다. 과거 평가를 새로 실행하거나 누락된 증거를 복원한 결과가 아니다.

| 발견한 한계 | 관측한 버전 | 개선 방향 | 확인 범위 |
|---|---|---|---|
| 명시한 편집 대상·색과 상태를 잃음 | v1 | 계열/표시별 명령 보존, 범례 표시와 위치 분리 | v1 새 UI 60문항 보고서. 원시 근거는 미확보 |

| 평가 문항 자체의 수학적 중복·단계 누출 | v2 준비 검토 | 순서에 따라 값이 달라지는 연산, 164단계 질문/기대 상태 분리 | 독립 검토와 보완본 검증. 제품 패치와 구분 |

제품 개선 외에 평가 실행기의 캡처 덮어쓰기, 재시도 범위, 준비 검사와 실제 실행의 혼동도 드러났다. 각 상세 문서에 이러한 한계를 제품 실패와 분리해 기록한다.

## 자료를 읽는 순서

1. 각 버전 문서에서 평가 목적, 첫 결과, 실패 사례와 개선을 확인한다.
2. [근거·누락 자료 목록](evidence.md)에서 이번에 직접 대조한 파일과 미확보 파일을 확인한다.
3. `records/`의 당시 서술 보고서와 이미 main에 있던 v1·v1.1 보고서를 확인한다. 보존 보고서의 로컬 경로·명령·해시는 당시 실행 문맥을 뜻한다.
4. 성능 재현이 필요하면 해당 시점의 제품·실행기·입력·원자료 조건부터 확보한다. 현재 main에서 새로 얻은 값으로 과거 점수를 대체하지 않는다.

## 공개 범위와 남은 검토

사용자의 요청에 따라 공개 개발 평가의 **서술 기록과 개선 이력**을 PR로 정리했다. 원시 예측·점수 JSON, API 원응답, 원자료 CSV/스냅샷, 화면/다운로드 파일, 인증 DB, `.env`, 키, 임시 실행기는 포함하지 않는다. 기존 `eval/publish-golden-records-20261028`의 자료 공개 작업과 별도이며, 이 PR은 그 브랜치의 전체 데이터셋·평가 결과 파일을 가져오지 않는다.

v1·v1.1의 원시 UI 실행 자료는 2026-10-29 로컬 점검에서 미확보다. 두 버전의 60/60·40/40은 기존 보고서의 기록으로 인용하며 현재 원시 자료까지 검증했다고 주장하지 않는다. 다른 버전도 선택한 점수 파일과 보고서를 대조한 범위이며 전체 산출물의 동결 해시를 재검증한 것은 아니다.

사람의 정답 승인, 참고 그래프·rubric 승인, 실제 제품 출력의 정성 승인, PR 코드 리뷰 승인은 각각 별개다. v1.4의 전달본 승인 기록은 제품 출력 50개의 정성 검토 완료를 뜻하지 않는다. AI가 수행한 시각·의미 검수는 사람의 최종 승인으로 표시하지 않는다.

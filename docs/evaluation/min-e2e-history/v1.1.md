# v1.1: 조회 조건·역질문 적절성과 추가 분류 평가

UI 평가일 2026-10-23 · 추가 분류 평가일 2026-10-27 · ai-assisted · 사람 결과 승인 대기

## 첫 평가와 실행 범위

조회 정확도 20문항과 역질문 적절성 20문항을 실제 UI·실제 KOSIS API로 확인했다. 각 문항은 새 대화에서 원문을 입력했으며, 질의에 제공된 대화 문맥과 명시 조건을 해석한 첫 응답을 평가했다. 후속 사용자의 답변을 받고 계산·출력을 재개하는 전체 다중 턴 흐름, 편집과 다운로드는 범위 밖이다.

| 항목 | 최초 응답 재채점 | 패치 후 `release2` UI |
|---|---:|---:|
| 데이터 조회 | 11/20 | 20/20 |
| 역질문 적절성 | 10/20 | 20/20 |
| UI 코호트 합계 | 21/40 | 40/40 |

초기 임시 22/40은 구 M2 제외와 필수 조건의 확인을 같은 기준으로 다시 판독해 21/40으로 정정했다. 최초 화면 일부는 후속 캡처에 덮어써져 당시 보존한 첫 API 응답으로 재채점한 값이다. 현재 그 원응답도 미확보이므로 이번 정리는 보고서에 근거한다.

## 부족했던 점과 개선

| 문제 | 대표 사례 | 개선 |
|---|---|---|
| 기관명·계열 기준 혼동 | 예금은행을 예금 요청으로 읽음, 신규/잔액을 상위 계열로 중복 선택 | 기관과 수신/대출 의미, 표 기준을 분리 |
| 명시 분류 누락 | 지역, 원계열/비계절조정, 시장가격 GDP, 연간 주기 | 승인 메타데이터의 항목·분류·주기에 연결 |
| 관측기간과 다른 연도 혼동 | SNA 기준연도·수록 시작연도, 인접 두 연도 요청 | 닫힌 조회기간과 기준연도 구분 |
| 통계명과 연산 혼동 | 항목명에 든 합계, 월별 산술평균 | 분류 이름과 실제 계산을 분리하고 표시기간과 선행 입력을 구분 |
| 필요한 기준을 묻지 않음 | M2 평잔/말잔·조정, 경제심리지수 계열, 물가 통화, 연간 대표값 | 결과를 바꾸는 미확정 기준만 확인 |
| 이미 정한 조건을 놓침 | 명시된 달러 기준이 이전 원화 합의와 중복됨 | 이번 요청의 명시적 변경을 우선하고 확정 조건 재질문 억제 |
| 실제 최신월을 자름 | 실제 제공 관측월을 오래된 카탈로그 종료월로 절단 | 요청한 계열의 실제 API 관측을 기준으로 종료월 결정 |
| 부분 문자열 오인과 반복 비용 | ‘이 자료’가 ‘이자’로 연결, 메타데이터 제목 반복 처리 | 의미 경계 보완, 정규식 캐시·선형 집계 |

관련 영역은 조건 파서, 카탈로그/정규 요청 계획, 요청 일치 검사, 기간 처리, 파생 계획과 API다. 당시 전체 파일에는 앞선 작업도 섞여 있어 파일 전체 diff를 이 패치만의 변경량으로 세지 않는다.

## 최종 UI 기록과 증거 한계

보고서의 최종 관측은 40/40이며 집중 회귀 20개, 호환성 회귀 42개, 전체 기본 검사 2,332개와 subtest 355개 통과, 빌드·v4.1 검증 통과다. 전체 테스트는 중복 없는 네 묶음으로 실행했다고 기록되어 있다.

초기 캡처 덮어쓰기, CQ1-16 뷰포트 PNG와 전체 DOM 사용, CQ1-17 조기 캡처 분리 후 새 대화 재제출 등의 제한이 있다. 최종 점수는 무재시도 최초 시도 점수로 부르지 않는다. 현재 `evaluation_runs/min-e2e-v1.1/`이 미확보이므로 캡처·원응답·동결 해시·테스트 로그를 이번에 재검증하지 못했다.

## 질의 유형 분류 20문항은 별도 실행이다

10월 27일 일반 10·파생 10문항을 섞고, 문항마다 새 Python 프로세스에서 제품의 `is_derived_request(query)`에 질문 문자열만 넣었다. 예측을 동결한 뒤 정답과 비교한 결과 20/20이다. 그 실행에서는 제품이나 라벨을 수정하지 않았다.

모델·UI·조회 수치의 평가는 아니다. 앞선 UI 40/40과 합쳐 ‘UI 60/60’으로 쓰지 않는다. 현재 로컬에는 이 실행의 보고서와 질문·예측·점수·동결 기록이 있다. 추가 문항과 관련 데이터셋 전체 공개 작업은 별도 브랜치에 있으며 이번 PR에는 서술 기록만 포함한다.
